# Changelog

All notable changes to **Nano66** will be documented in this file.

## [1.0.0] - 2026-11-13

### Added
- **Core Animation Engine**: Multi-stage DOM-aware particle construction pipeline.
- **PixiJS v8 GPU Renderer**: WebGL rendering with batch sprite container and canvas 2D fallback.
- **Text Rasterization Target Generation**: Exact glyph sampling from Canvas 2D masks following font styles.
- **Shape & Image Target Generators**: Border-radius silhouette sampling and safe CORS fallback for images.
- **Layout-Preserving Concealment**: Invisible layout preservation without layout shifts or flashing.
- **Cursor Attraction**: Final dust vortex convergence toward mouse cursor.
- **Auto Theme Detection**: Dark / light luminance analysis and custom palettes.
- **Performance Monitor**: Dynamic FPS tracking, adaptive particle presets (low, balanced, ultra).
- **Accessibility**: Automatic detection of `prefers-reduced-motion` with immediate reveal option.
- **Full Test Suite**: 26 Vitest unit tests and 12 Playwright real-browser integration tests across Vanilla and React.
