WEB ANIMATION ENGINE

Every website.
Built from particles.

Nano66 is a production-quality, framework-agnostic DOM-aware website construction animation engine. It assembles your real website element by element using millions of microscopic GPU particles, then absorbs remaining dust into the visitor's cursor.

Core Philosophy

Unlike conventional particle background effects or 3D canvas canvases, Nano66 is DOM-aware. It does not replace your website with a pre-rendered 3D scene. Instead, it captures the positions, computed typography, borders, and silhouettes of your real DOM elements, conceals them without triggering layout shifts, constructs each element from microscopic particles, and seamlessly reveals your authentic HTML elements into an interactive state.

GPU Accelerated

Built on PixiJS v8 with batched sprite rendering and Canvas 2D fallback.

True Glyph Rasterization

Letter-exact particle targets generated directly from font shapes via Canvas 2D masks.

Zero-Allocation Object Pool

Pre-allocated buffers eliminate garbage collection pauses during 60 FPS animation.

Framework Independent

Compatible with React, Next.js, Vue, Nuxt, Svelte, Angular, and Vanilla JavaScript.

Quick Start

Add Nano66 to your application with minimal boilerplate:

import { Nano66 } from "nano66";

// Initialize the engine
const nano = new Nano66({
  target: "body",
  theme: "auto",
  animation: {
    mode: "sequential",
    cursorExit: true,
  },
  particles: {
    count: 4000,
    glow: true,
  },
});

// Start construction animation
nano.start();

Configuration Reference

Option Type Default Description
target string | HTMLElement "body" Target DOM container to scan and animate.
animation.mode "sequential" | "grouped" | "parallel" "sequential" Construction sequencing mode.
animation.elementDelay number 250 Delay between sequential element starts in milliseconds.
animation.cursorExit boolean true Attract remaining dust particles into mouse cursor upon completion.
animation.revealThreshold number (0.1 - 1.0) 0.8 Percentage of arrived particles before revealing the original DOM element.
particles.count number 4000 Total number of active particles. Auto-scaled by preset if omitted.
particles.size number | [min, max] [1.2, 2.8] Particle radius in CSS pixels.
particles.color string | string[] | "auto" "auto" Particle color palette. Automatically adapts to dark/light theme when auto.
particles.glow boolean true Enables additive blending mode for luminous glowing particles.
performance.preset "low" | "balanced" | "ultra" "balanced" Performance tier tuning particle densities for target hardware.
accessibility.respectReducedMotion boolean true Respects OS prefers-reduced-motion preference with immediate reveal.

HTML Data Attributes

Control element construction declaratively in HTML:

Attribute Example Description
data-nano-order <h1 data-nano-order="1"> Defines exact numerical construction order.
data-nano-group <div data-nano-group="cards"> Groups elements together for concurrent grouped construction.
data-nano-ignore <nav data-nano-ignore> Bypasses concealment and animation, remaining visible throughout.
data-nano-card <article data-nano-card> Forces boundary and interior sampling for container elements.

// Event subscriptions

Framework Guides

React & Next.js

import { useEffect, useRef } from "react";
import { Nano66 } from "nano66";

export function Portfolio() {
  const rootRef = useRef(null);

  useEffect(() => {
    if (!rootRef.current) return;
    const nano = new Nano66({ target: rootRef.current });
    nano.start();

    return () => nano.destroy();
  }, []);

  return <div ref={rootRef}>...</div>;
}

Performance Presets

Nano66 provides three pre-tuned performance tiers:

  • Low: ~1,500 particles with simplified flow physics. Ideal for low-power smartphones and older devices.
  • Balanced (Default): ~4,000 particles with full vector fields, glow blending, and text glyph rasterization.
  • Ultra: ~8,000+ particles with high-density surface point sampling for 4K displays and dedicated GPUs.

Troubleshooting & FAQ

Q: Does Nano66 interfere with my site's responsive CSS or accessibility?

A: No. Nano66 preserves the real DOM structure. Layout-preserving visibility techniques ensure dimensions remain intact without layout reflow, and original elements are revealed with full interactive functionality.

Q: What happens if an image fails CORS security checks?

A: Nano66 catches Canvas security exceptions gracefully and constructs the image silhouette boundary outline without halting the animation.
